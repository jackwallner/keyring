## Decisions

- Control arm is exactly today's onboarding copy: "Start free trial" when the Apple Account is trial-eligible, "Continue with Pro" when not. Neither changes for any customer with no metadata set.
- The paywall button is not a trial button. It reads "Continue with Pro" by design (`ConversionCopy.ctaLabel`, App Review 3.1.2(c): no pricing or trial words on the button). It is not routed through `TrialCTA`. Adding "my" or "your" trial wording there would change the paywall design, so it is held for Jack.
- There is no trial sheet in this app, and no string catalog (English only), so no translations were needed.
- Switch keys (`rating_prompt`) must be set identically on every offering so an Experiment arm cannot flip them. Noted in AGENTS.md.
- To run a wording test: set offering metadata `trial_cta` to `my` or `your` on an Experiment's variant offering. Read results by Experiment or by the `trial_cta` subscriber attribute.

## Held for Jack
